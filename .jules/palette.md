## 2024-06-15 - Implement Clear Button in Search Bar
**Learning:** Users need a quick way to clear the search input, especially since it drives autocomplete and primary navigation. A clear button improves accessibility and user experience by providing a one-click reset action.
**Action:** Add an accessible, visible clear button (e.g., using the `X` icon) when the input has content. Ensure keyboard focus is restored to the input upon clearing, and that any autocomplete/suggestion states are immediately reset.
