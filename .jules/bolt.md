## 2024-05-19 - Use Map insertion order for LRU cache and caching high-frequency routes
**Learning:** In Node.js / JavaScript, `Map` objects preserve insertion order. To build an efficient LRU (Least Recently Used) cache, you can evict the oldest entry using `map.keys().next().value`. However, updating an existing key via `set` does *not* automatically refresh its insertion order—you must explicitly `delete` it first and then `set` it again to push it to the end of the insertion order. Also, autocomplete and suggestion API routes that are called on every keystroke are prime targets for in-memory caching to save on external redundant network requests and parse time.
**Action:** When implementing LRU logic using a Map, always explicitly `delete(key)` before `set(key, value)` to refresh recency. Look out for high-frequency autocomplete/typeahead routes as critical candidates for caching.
