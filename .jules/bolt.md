## 2026-07-01 - Unbounded memory leaks in API caching
**Learning:** Next.js API routes sharing an in-memory cache without a maximum capacity will lead to unbounded memory growth (Out-Of-Memory leaks), particularly on high-frequency autocomplete endpoints like /suggest. While a TTL deletes old items on access, it does not prevent memory saturation during high traffic spikes. Javascript's `Map` object insertion order can be effectively utilized for LRU cache eviction.
**Action:** When implementing in-memory caching within Next.js API routes or long-running Node.js processes, always enforce a maximum size limit using LRU eviction (`if (cache.size > MAX) cache.clear()` or targeted keys) in addition to TTL, and remember that `Map.prototype.set` requires explicit deletion and re-insertion to refresh insertion order.
