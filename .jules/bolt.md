## 2026-06-07 - Prevent unbounded memory growth with LRU cache in Next.js backend
**Learning:** Implementing in-memory caching with a simple `Map` can lead to unbounded memory growth and Out-Of-Memory (OOM) leaks in long-running processes (like Next.js backend API routes handling high-frequency queries). A native JavaScript `Map` preserves insertion order, allowing for an efficient Least Recently Used (LRU) eviction strategy by evicting the oldest item (`map.keys().next().value`) and explicitly deleting and re-inserting keys on access/update to refresh their recency.
**Action:** When implementing in-memory caching within Next.js API routes that handle user-generated input, always enforce a maximum size limit (`maxSize`) and consider an LRU pattern to cap memory usage while maintaining cache efficiency for frequent queries.
