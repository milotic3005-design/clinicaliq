## 2024-05-23 - API Caching & LRU Map Eviction
**Learning:** High-frequency API routes like autocomplete (`/api/v1/suggest/route.ts`) can cause severe bottlenecks when not cached, leading to redundant external API calls. Furthermore, simple `Map`-based caching without an eviction policy leads to memory leaks. JavaScript's `Map` object preserves insertion order, allowing for an elegant LRU cache implementation by evicting `map.keys().next().value`. However, `Map.prototype.set` does not update the insertion order of an already-existing key; you must `delete` it first.
**Action:** When implementing in-memory caches for user-generated input, always use an LRU pattern with a size limit (`maxSize`). Ensure to explicitly `delete` keys before re-inserting them during `get` or `set` operations to correctly update their recency in the `Map` insertion order.
