## 2023-10-27 - Remove WebCrypto subtle async digest for simple in-memory cache keys
**Learning:** Using `crypto.subtle.digest` via the WebCrypto API is incredibly inefficient for short strings in a Node.js environment due to text encoding, ArrayBuffer conversion, and especially the async promise creation overhead. In an aggregator making multiple backend calls using an in-memory `Map` cache, simple string manipulation (like `toLowerCase().trim()`) as the cache key is dramatically faster (milliseconds compared to over a second for 10k iterations) and prevents unnecessary async/await event-loop bloat.
**Action:** Always favor synchronous, simple cache keys (like standard strings) for purely in-memory caches, avoiding cryptographic hashing unless the key needs normalization/masking for security or length-constraints (like in an external KV store).
