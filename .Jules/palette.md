## 2026-05-08 - Adding ARIA labels to interactive elements
**Learning:** Interactive UI components that toggle state or lack descriptive text require explicit ARIA attributes like `aria-expanded` and `aria-label` for screen reader users to understand their purpose and current state.
**Action:** Ensure custom UI elements like accordions and icon-only buttons include `aria-label` and state-indicating attributes like `aria-expanded` from the beginning of implementation.
