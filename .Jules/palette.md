## 2026-05-03 - Search Bar Clear Interaction
**Learning:** Adding a dedicated clear button and Escape-key-to-clear logic to a custom search input component significantly improves the UX of repetitive searches. However, when the search input displays a loading spinner inside the input container (e.g., right-aligned absolute position), the clear button must replace or share this space gracefully. It's critical to ensure the right padding of the text input accommodates both to prevent text overlap, and to immediately refocus the input field after clicking the clear button so the user can immediately resume typing.
**Action:** When implementing a clear button for text inputs that also include loading spinners or icons inside the input element, always verify the input padding (`pr`) and absolute positioning relative to these dynamic UI elements to avoid visual collision, and use `inputRef.current?.focus()` to keep the interaction seamless.
